## 1) إصلاح مشكلة الكيبورد في شاشة الـ PIN (أندرويد)

### المشكلة
عند محاولة إيقاف أو تشغيل الحماية تظهر شاشة إدخال الـ PIN، لكن كيبورد الجهاز **لا يفتح إطلاقًا** — فلا يستطيع المستخدم كتابة الرقم السري.

### السبب الجذري
كان الحقل المستخدم لالتقاط الأرقام حقلًا مخفيًا بمقاس `1dp × 1dp` (في `activity_pin.xml`). معظم لوحات المفاتيح — بما فيها **Gboard** — ترفض فتح الكيبورد لأي Editor غير مرئي أو بحجم شبه معدوم، لأن النظام يعامله كأنه ليس على الشاشة.

### الإصلاح (3 تغييرات)

| الملف | التغيير | لماذا |
|---|---|---|
| `activity_pin.xml` | تحويل الحقل من `1dp` إلى **Layer شفاف بمساحة لمس حقيقية** (`match_parent × 56dp`) موضوع فوق صف النقاط مباشرة داخل `FrameLayout`، مع `textColor` شفاف و`background` شفاف و`cursorVisible=false` | الكيبورد يفتح للحقول "الحقيقية المرئية" فقط؛ النص شفاف فلا يظهر للمستخدم أي شيء — فقط النقاط المتحركة تُمثل الأرقام |
| `PinActivity.kt` | إضافة `window.setSoftInputMode(SOFT_INPUT_STATE_ALWAYS_VISIBLE)` | النافذة تطلب الكيبورد بقوة لحظة الفتح بدل الطلب "الضعيف" `SHOW_IMPLICIT` وحده |
| `PinActivity.kt` | إعادة محاولة فتح الكيبورد عند `onWindowFocusChanged` + بعد `postDelayed(400ms)` | بعض الـ IMEs تتجاهل الطلب المُرسل قبل اكتمال عرض النافذة |

كذلك الحقل الآن **قابل للنقر** (`setOnClickListener → showKeypad`) وقابل لالتقاط الـ focus عند لمس منطقة النقاط.

### كيف تم التحقق (على جهاز حقيقي عبر ADB)
1. `./gradlew assembleDebug` → بناء ناجح
2. `adb install -r` → تثبيت على الجهاز
3. تدفق كامل مُختبر بأتمتة `uiautomator`:
   - `pm clear` → Splash → Welcome onboarding → MainActivity
   - تفعيل PIN من الإعدادات (`SetPinActivity`) وحفظه بنجاح
   - تشغيل الحماية → الضغط على زر الطاقة → فتحت `PinActivity`
   - **`dumpsys input_method` أثبت `mInputShown=true`** — الكيبورد يفتح
   - إدخال PIN صحيح → `pin_verified=true` في `shared_prefs` → الحماية توقفت وعاد المستخدم للرئيسية

## 2) صفحة الهبوط — النظرة العامة

**الملف:** `website/index.html` — صفحة واحدة، ملف واحد، **بدون أي framework**.

| البند | الاختيار | السبب |
|---|---|---|
| البنية | HTML + CSS + Vanilla JS في ملف واحد | صفحة هبوط واحدة لا تبرر أي build step؛ تُفتح مباشرة من أي static host (GitHub Pages، أي خادم) |
| الخطوط | Google Fonts: **Cairo** (400, 500, 700, 800) + **IBM Plex Sans** (400, 500, 600) | Cairo للعربية RTL أولًا، Plex للاتينية الصغيرة فقط (URLs، تسميات) |
| الاتجاه | `<html lang="ar" dir="rtl">` | عربي أولًا في كل شيء |
| الصور | لا يوجد أي ملف صور — كل شيء SVG مضمّن (inline) | وزن أقل، حِدة كاملة على كل الشاشات، وتحكّم كامل في الألوان من CSS |

### بنية الصفحة (4 أقسام، بالترتيب)
1. **Hero** — Night Indigo كامل الشاشة، مع أنيميشن رسم القوس
2. **Demo تفاعلي** — محاكاة هاتف داخل الصفحة، 3 أزرار مواقع تُجرّب الحجب فعليًا
3. **الثقة والخصوصية** — خلفية Indigo 2، قائمة بسيطة بلا بطاقات
4. **Footer** — العلامة فقط، بلا روابط

## 3) الألوان وأدوارها

قاعدة صارمة: **كل لون له وظيفة واحدة فقط** — لا استثناءات، ولا ألوان خارج هذه الستة.

```css
:root{
  --indigo:#1B1F3B;   /* الخلفية الداكنة الأساسية — الـ Hero */
  --indigo-2:#242952; /* سطح داكن ثانوي — قسم الثقة */
  --amber:#C9A15C;    /* اللون المميز الوحيد — زر CTA فقط */
  --sage:#7A9471;     /* حالات النجاح والسماح فقط */
  --sage-ink:#5D7857; /* خط صغير من عائلة Sage للتباين فقط */
  --sand:#F7F1E6;     /* الخلفية الفاتحة + النص فوق الداكن */
  --char:#2B2A28;     /* نص المقال فوق الفاتح */
}
```

| اللون | وظيفته | أين يظهر | أين **لا** يظهر أبدًا |
|---|---|---|---|
| `#1B1F3B` Night Indigo | الخلفية الداكنة الرئيسية | Hero، شاشة الهاتف المحجوبة، الـ Footer | — |
| `#242952` Indigo 2 | سطح داكن أفتح قليلًا | خلفية قسم الثقة فقط | — |
| `#C9A15C` Amber Gold | **المميز الوحيد** (CTA) | زر "حمّل حِصن"، النقطة الفاصلة في chip الموقع غير المعروف | لا يعني أبدًا "نجاح" |
| `#7A9471` Sage Green | النجاح/السماح فقط | علامة الصح عند فتح موقع سليم، تعبئة القوس، نقطة chip المسموح | لا يعني أبدًا "تحذير" |
| `#5D7857` Sage Ink | خط صغير من نفس عائلة Sage عند الحاجة لتباين أعلى | حد علامة الصح الصغيرة فقط | لا يستخدم كملء كبير أو لون حالة جديد |
| `#F7F1E6` Sand White | الفاتح/النص فوق الداكن | خلفية Demo، نصوص Hero وFooter | — |
| `#2B2A28` Deep Charcoal | نص أساسي فوق الفاتح | نصوص قسم Demo | — |

- **لا أحمر إطلاقًا** — حتى شاشة الحجب داخل الهاتف هادئة بلا أي إنذار.
- التعديل الوحيد المسموح: شفافية النص الفاتح فوق الداكن عبر `rgba(247,241,230,.85 / .72 / .68 / .5)` — وهي نفس قيمة Sand بألفا مختلفة، ليس لونًا جديدًا.
- ظل واحد فقط في الصفحة كلها: تحت إطار الهاتف `box-shadow:0 36px 70px -28px rgba(27,31,59,.45)` — كما طلب التصميم.
- `::selection` خلفيته Amber ونصه Indigo — لحظة العلامة الوحيدة خارج الزر.

## 4) علامة الشعار (Logo Mark)

**الشكل:** قوس بوابة (horseshoe/keyhole arch) — كما في عمارة القلاع العربية/الإسلامية. ساقان مستقيمان ينحنيان إلى قبة واحدة مدوّرة — مثل حرف «ن» بدون نقطة.

**ليس:** قفلًا، درعًا، أو علامة صح.

### بنية الـ SVG (ثلاث طبقات بالترتيب البصري)

```html
<svg viewBox="0 0 200 200">
  <!-- 1) التعبئة الداخلية: Sage -->
  <path class="mark-fill" d="M40 190 V95 C40 45 65 15 100 15
                             C135 15 160 45 160 95 V190 H40 Z"/>
  <!-- 2) الحد الخارجي: Amber، بدون خط قاعدة سفلي (مفتوح للأسفل) -->
  <path class="mark-outline" pathLength="100" d="M40 190 V95 C40 45 65 15 100 15
                                                 C135 15 160 45 160 95 V190"/>
  <!-- 3) الشق الرأسي المركزي: بلون الخلفية — يقرأ كقطعة مقطوعة -->
  <rect class="mark-slit" x="96" y="60" width="8" height="130"/>
</svg>
```

- `pathLength="100"` — يجعل قياس الأنيميشن مستقلًا عن طول المسار الفعلي (راجع قسم الأنيميشن).
- مسار الـ outline **مقصوص عنده الأسفل** (`V190` من دون إغلاق `H40 Z`) حتى تُرى البوابة "قائمة على الأرض".
- الشق (`mark-slit`) لونه `var(--mark-surface, var(--indigo))` — أي **بلون الخلفية** فيُقرأ كقطع cut-through وليس كخط مرسوم.
- لون `mark-slit` يجب أن يساوي دائمًا لون السطح الذي تقع عليه العلامة — لا يكون لونًا ثابتًا أبدًا.
- نفس الـ SVG يعمل كـ **favicon** مضمّن في `data:image/svg+xml` بألوان hex مشفرة.

### أين تُستخدم العلامة
1. الـ Hero — بحجم كبير مع الأنيميشن
2. داخل شاشة الحجب في الهاتف — نسخة صغيرة هادئة (شعار الشركة لا أيقونة تحذير)
3. الـ Footer — بلا أي نص جانبي

## 5) الخطوط (Typography)

| الخط | الأوزان | الاستخدام |
|---|---|---|
| **Cairo** | 800 | كل العناوين (h1, h2, `strong` في قائمة الثقة، الـ wordmark) |
| **Cairo** | 400–500 | نص المقال، الأزرار، الـ chips |
| **IBM Plex Sans** | 400–600 | التسميات اللاتينية فقط: شريط الـ URL داخل الهاتف، أسماء النطاقات على الـ chips، `HISN` في الفوتر |

- `dir="ltr"` على كل نص لاتيني (URLs) حتى لا يقلبه الـ RTL العام — مع `text-align:left` و`text-overflow:ellipsis`.
- أحجام العناوين بـ `clamp()` — تتدرج سلسًا من الجوال حتى الديسكتوب بلا نقاط قفز.
- لا **letter-spacing** متباعد على أي عربي (يفسد اتصال الحروف) — فقط `.14em` على `HISN` اللاتينية الصغيرة.

## 6) لحظة الأنيميشن الوحيدة

**مرة واحدة عند تحميل الصفحة فقط.** لا لوب، لا bounce، لا fade-in عند السكرول. التتابع:

| الزمن | ما يحدث | التقنية |
|---|---|---|
| 0.15s → 1.95s | الحد الكهرماني **يرسم نفسه** قلميًا (~1.8s) | `stroke-dasharray:100; stroke-dashoffset:100` + `@keyframes draw{to{stroke-dashoffset:0}}` — مع `pathLength="100"` يصبح القياس بسيطًا 0→100 مهما كان طول المسار الفعلي. المنحنى: `cubic-bezier(.65,.05,.36,1)` (بداية واثقة، نهاية هادئة) |
| 1.95s → 2.85s | تعبئة الـ Sage **تظهر** داخل القوس (~0.9s) | `@keyframes appear{to{opacity:1}}` على `.mark-fill` |
| 2.85s → 3.35s | **الشق** يظهر أخيرًا | نفس `appear` على `.mark-slit` |
| 3.15s → … | العنوان **يصعد** إلى مكانه | `@keyframes rise` (`opacity:0 + translateY(18px)` → طبيعي) بـ `cubic-bezier(.22,.61,.36,1)` |
| 3.5s | الجملة المساندة تصعد | نفس `rise` بتأخير أكبر |
| 3.75s | زر الـ CTA يصعد | نفس `rise` |

- إجمالي التتابع ~4.5s — أطول من المعتود بقليل لكنه **توقيع العلامة**: القوس يُبنى أمامك ثم تُفتح البوابة "المغلقة".
- **احترام تفضيل تقليل الحركة:**

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation:none!important;transition:none!important}
  .rise{opacity:1;transform:none}
  .hero-mark .mark-fill,.hero-mark .mark-slit{opacity:1}
  .hero-mark .mark-outline{stroke-dashoffset:0}
}
```
كل شيء يظهر فورًا في حالته النهائية — لا يُحرم المستخدم من المحتوى.

## 7) الأقسام بالتفصيل

### 7.1 الـ Hero
- خلفية Night Indigo **كامل الشاشة** (`100svh` — الوحدة الصحيحة للموبايل مع شرط ساقط `100vh` كبديل).
- المحتوى متمركز بالوسط (`place-items:center`) — تكوين بوابة: العلامة فوق، الكلام تحتها.
- العنوان: «ما لا يليق لا يصل، وكل شيء آخر يبقى كما هو.» — يشرح السلوك لا صفات تسويقية.
- جملة مساندة واحدة: تشرح **كيف** يعمل (فلترة داخل الجهاز، بلا مراقبة) لا شعارات.
- زر Amber واحد: «حمّل حِصن» → GitHub. أسفله سطر صغير يوضح أنه مجاني لأندرويد وأن الرابط ينتقل إلى GitHub لتحميل ملف التطبيق وتثبيته يدويًا.
- حالة hover للزر: الخلفية تتحول إلى Indigo والنص إلى Sand مع الرفع الموجود — تغيير واضح عالي التباين ضمن نفس الألوان.

### 7.2 الـ Demo التفاعلي (قلب الصفحة)
**ليس لقطة شاشة ثابتة — الزائر يجرّب الحجب بنفسه.**

**بنية إطار الهاتف:**
```
.phone (312px، نسبة 9/16، Indigo إطار، radius 38px)
└── .screen (خلفية Sand)
    ├── .browser-top → شريط URL حقيقي المظهر (Plex Mono-style pill)
    └── .page (منطقة المحتوى)
        ├── #viewOk     → صفحة مفتوحة "عادية" + سطر حالة في الأسفل
        └── #viewBlock  → لوحة Indigo هادئة (hidden افتراضيًا)
```

- **الصفحة "المفتوحة"**: هيكل وهمي لصفحة ويب (عنوان + أسطر نص + صورة) بعناصر `div` بلون `rgba(43,42,40,.08–.13)` — يقرأ كصفحة عادية بلا رسم تفصيلي زائد.
- **سطر الحالة**: علامة صح SVG صغيرة بحد Sage Ink (`stroke:var(--sage-ink)`) + «فتح الموقع بشكل طبيعي».
- **صفحة الحجب**: خلفية Indigo، **العلامة نفسها** (نفس الـ SVG الثلاثي)، الرسالة: «هذا الموقع غير متاح على هذا الجهاز.» وجملة هادئة: «أغلق الصفحة وواصل يومك كما كان.» — **لا أحمر، لا اهتزاز، لا أيقونة تحذير.**

**الـ Chips الثلاثة:**

| Chip | النطاق | ما يحدث عند الضغط |
|---|---|---|
| موقع مرجعي | `ar.wikipedia.org` | الصفحة المفتوحة + عنوانها يتغير («الموسوعة الحرة») + صح Sage |
| موقع بنكي | `www.nbe.com.eg` | الصفحة المفتوحة + عنوانها يتغير («خدماتك المصرفية…») + صح Sage |
| رابط غير معروف | `unknown-link.xyz` | شاشة الحجب الهادئة |

**الـ JS المسؤول (vanilla، ~30 سطرًا):**
```js
const sites = {
  wiki:   { url:'ar.wikipedia.org', title:'الموسوعة الحرة', ok:true },
  bank:   { url:'www.nbe.com.eg',  title:'خدماتك المصرفية عبر الإنترنت', ok:true },
  unknown:{ url:'unknown-link.xyz', ok:false },
};
```
عند الضغط: يُحدَّث نص شريط الـ URL، ويُبدَّل `hidden` بين العرضين، ويُدار التفعيل البصري للـ chip (`classList.toggle('on')` + `aria-pressed`). لا شيء آخر — لا مكتبات، لا state management.

- سطر الـ URL داخل الهاتف `aria-hidden="true"`، و`aria-live="polite"` على منطقة المحتوى — قارئ الشاشة يعلن التغيير دون إعادة قراءة النطاق كنص مكرر.

### 7.3 قسم الثقة والخصوصية
- خلفية **Indigo 2** (`#242952`) — تمييزه عن الـ Hero دون خلق لون جديد.
- عنوان: «كل الفحص يحدث داخل جهازك. لا شيء يغادره.» + جملة: «هذه ليست وعودًا تحتاج تصديقها — إنها طريقة عمل حِصن تقنيًا.»
- **قائمة عادية `<ul>` بلا أرقام وبلا بطاقات** — كل عنصر: سطر فاصل رفيع أعلى (`border-top:1px solid rgba(...,.16)`) + `strong` كعنوان + فقرة شرح.
- المحتوى الخمسة (بلغة عادية أولى):
  1. الفلترة على الجهاز بالكامل — لا يمر طلبك عبر أي خادم لنا
  2. تاريخ التصفح لا يُسجَّل ولا يُرسل — لا نعرف ما فتحت
  3. يمكنك إيقافه متى شئت — من إعدادات الجهاز، بلا أسئلة
  4. قائمة الحظر تتحدّث وحدها في الخلفية — بلا تدخل منك
  5. الكود مفتوح المصدر — رابط نصي عادي إلى GitHub حتى يستطيع أي شخص مراجعته والتأكد من عدم وجود تتبع مخفي
- بعد القائمة مباشرةً توجد نسخة ثانية من زر «حمّل حِصن» بنفس وجهة وشكل زر الـ Hero.

### 7.4 الـ Footer
- Night Indigo، المحتوى متمركز بالوسط.
- **العلامة + حِصن + HISN فقط.** لا روابط، لا link farm، لا أعمدة.
- `HISN` بـ Plex 600 ووزن حجم صغير — التسمية اللاتينية الوحيدة.

## 8) التجاوب مع الشاشات (Responsive)

- نقطة الكسر الوحيدة: `max-width:720px`.
- **موبايل:** padding الأقسام 88px بدل 120px، الهاتف بعرض `min(312px, 84vw)` (لا يتجاوز الشاشة أبدًا)، الـ chips تلتف `flex-wrap` وتصغر المسافات، عناوين الثقة تنزل لـ 17.5px.
- الـ Hero يستخدم `100svh` (مع fallback `100vh` قبلها) — الوحدة التي تحل مشكلة شريط العناوين الديناميكي في متصفحات الجوال.
- كل الأحجام المتغيرة بـ `clamp()` — لا قفزات بين نقاط الكسر.

## 9) إمكانية الوصول (Accessibility)

| الضمان | التطبيق |
|---|---|
| **حالة focus مرئية** | `:focus-visible{outline:2px solid var(--amber);outline-offset:3px}` على الأسطح الداكنة، و`.on-light :focus-visible{outline-color:var(--indigo)}` للـ chips فوق Sand |
| **العلامة لها اسم** | في الـ Hero: `role="img" + aria-label` كامل؛ حيث تكون زخرفة (الهاتف، الفوتر): `aria-hidden="true"` |
| **الـ chips أزرار حقيقية** | `<button>` مع `aria-pressed` يتحدث مع كل ضغطة — قارئ الشاشة يقول "مضغوط/غير مضغوط" |
| **تغييرات الـ Demo معلنة** | `aria-live="polite"` على منطقة العرض |
| **تقليل الحركة** | `prefers-reduced-motion:reduce` يوقف كل الأنيميشن ويعرض الحالة النهائية فورًا |
| **التباين** | Sand (#F7F1E6) فوق Indigo (#1B1F3B) — نسبة تتجاوز AA بوضوح؛ Char (#2B2A28) فوق Sand كذلك |

## 10) قواعد الكتابة والتصميم المُتَّبعة

**مُتَّبعة بالكامل — وما يلي كيف:**

| القاعدة | التنفيذ |
|---|---|
| بلا SaaS-card kit | لا توجد بطاقات متطابقة بظلال — قسم الثقة قائمة نصية بفواصل، الـ Demo تخطيط حر |
| بلا عناوين eyebrow بأحرف متباعدة | لا يوجد أي tracked-out all-caps فوق الأقسام |
| بلا فواصل نقطة وسطى · | لا يوجد |
| بلا أسهم → على الأزرار/الروابط | لا يوجد أي arrow glyph |
| بلا ترقيم 01/02/03 | القائمة في قسم الثقة `<ul>` بلا أرقام (المحتوى ليس خطوات متسلسلة أصلًا) |
| كلام عادي مبتدئ لا صفات تسويقية | «الفلترة تعمل داخل الهاتف نفسه» بدل «حلول احترافية متكاملة» — كل جملة تشرح **ماذا يحدث** |
| مسطح تمامًا | لا gradients، لا glassmorphism، ظل واحد فقط تحت الهاتف (كما سمح التصميم) |
| لا لوب/أنيميشن سكرول | أنيميشن واحد عند التحميل فقط |

## 11) الأدوات والتقنيات المستخدمة

### صفحة الهبوط
| الأداة/التقنية | الاستخدام |
|---|---|
| **HTML5 دلالي** | `main`, `section`, `ul`, `button`, `footer` |
| **CSS Grid + Flexbox** | تمركز الـ Hero (`place-items:center`)، تخطيط الصفحة |
| **CSS Custom Properties** | لوحة الألوان الستة في `:root` — تغيير أي لون من سطر واحد |
| **SVG inline** | العلامة (بكل أحجامها)، favicon، علامة الصح — بلا أي ملف صور خارجي |
| **pathLength + stroke-dash** | تقنية رسم القوس بالأنيميشن |
| **clamp() / svh / aspect-ratio** | تجاوب حديث بلا media queries زائدة |
| **Vanilla JS** | منطق الـ Demo فقط (~30 سطرًا) — بلا jQuery، بلا React، بلا أي dependency |
| **Google Fonts** | Cairo + IBM Plex Sans مع `preconnect` و`display=swap` |
| **prefers-reduced-motion** | احترام تفضيل تقليل الحركة |

### جانب الأندرويد (جلسة العمل)
| الأداة | الاستخدام |
|---|---|
| **Gradle** (`./gradlew assembleDebug`) | بناء الـ APK |
| **ADB** (`install`, `shell`, `input`, `pm clear`) | التثبيت، محاكاة اللمس والكتابة، التحقق من الحالة |
| **uiautomator dump** | قراءة شجرة الـ UI للتحقق من العناصر وإحداثياتها |
| **dumpsys** (`window`, `input_method`, `activity`) | التحقق الرسمي: `mInputShown=true` = الكيبورد مفتوح فعلًا |
| **Kotlin** (`PinActivity.kt`) | منطق فتح الكيبورد القوي |
| **Material XML layouts** | `activity_pin.xml` — إعادة هيكلة الحقل الشفاف |

## 12) كيف تشغّل وتختبر

### صفحة الهبوط
```bash
# من جذر المشروع — أي خادم ملفات يكفي:
python3 -m http.server 8765 --directory website
# ثم افتح http://localhost:8765
```
أو ارفع مجلد `website/` كما هو على GitHub Pages / أي static host — **لا build step مطلوب**.

### اختبر سريعًا:
1. **أعد تحميل الصفحة** — شاهد تتابع رسم القوس (مرة واحدة، لا يتكرر)
2. **اضغط chip «رابط غير معروف»** — شاشة الحجب الهادئة تحل محل الصفحة
3. **اضغط chip الموسوعة أو البنك** — عودة لصفحة مفتوحة + صح Sage
4. **Tab** عبر الأزرار — حلقة focus Indigo فوق الـ chips الفاتحة، وكهرمانية فوق الأسطح الداكنة
5. **قلّل عرض النافذة تحت 720px** — التخطيط ينكمش سلسًا

### تطبيق الأندرويد
```bash
cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
